# TLOB_ADAPTED

Official source: https://github.com/LeonardoBerti00/TLOB at `f1c0af4d81067978914361766db0457a7d8b6a46` (MIT, copyright 2026 LeonardoBerti). Exact upstream source files and license are retained under scripts/qf_overnight/vendor_tlob/original and vendor_tlob/LICENSE, with Git blob/SHA256 mapping in upstream.json. No pretrained weights or event datasets were acquired.

The dual temporal/feature attention, precomputed Q/K/V plus MultiheadAttention projections, residual paths, MLPs and final dimensional reductions are from the official implementation. Official default hidden40, four dual layers, one attention head and sinusoidal positions are retained. Input width changes to the frozen13 aggregate features; sequence length changes from128 to38 daily origins. The unused event order-type embedding is removed. Actual trainable parameter count is191672. There is no added asset embedding or peer input. This model is not parameter-matched to UA/UC. The official architecture has no dropout layers; no generic Transformer substitution or extra dropout was introduced.

For each origin, the adapter passes that asset's entire same-day history from09:00 through that origin. The fixed38-slot input repeats the current vector in slots after the origin; these are deterministic padding, not future observations. Actual observed history keeps its original position indices. This padding permits the official fixed-dimension BiN/feature-attention architecture while making its bidirectional operations causal per origin. Earlier logits are invariant to changes in future original observations; day batches are independent. This is a disclosed architectural adaptation, not a claim to reproduce event-level TLOB performance.

Device allocation follows the input/model device. Sinusoidal positions become a registered buffer. Unused visualization/einops dependencies are removed with equivalent permutations. BiN's feature standard deviation receives the same below1e-4-to-one protection already used on its temporal dimension. Negative BiN mixing weights use a functional .01 fallback, replacing the upstream forward-time creation of new CUDA Parameters, which would break optimizer ownership and retained/checkpointed gradients. Activation checkpointing and prefix microchunks cap memory; neither changes features, labels or the effective32 day-panel optimizer window. No GPU package installation was needed.

The bounded adapter effort started at approximately15:38 UTC and achieved passing real-data two-epoch training, saved full validation/holdout predictions, output-shape/finite checks, no-future/no-cross-day checks at15:52 UTC. Training smoke artifacts remain local and are excluded from scientific full-fit counts. See tlob_gates.json. The finite TLOB search/selection/confirmation jobs were predeclared before implementation. Core source files remain unchanged from the reviewed transport correction commit.
